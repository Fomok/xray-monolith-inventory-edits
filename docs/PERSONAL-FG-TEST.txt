Squared Away Personal DLSS FG Test 7 Scope Diagnostics - EXPERIMENTAL

INSTALL
1. Quit the game. Back up the complete Test 6 engine package.
2. Copy this complete engine package to the separate personal test game.
3. Install Squared Away Personal FG Test 6 UI and Scope Shader.zip as a separate
   MO2 mod below DLSS FSR3 Compatibility Patch and Bodycam patches. Its three
   files must win. This is required for the matching optical map and controls.
4. Keep OptiScaler Dual FPS Test 1 (dxgi.dll), the Test 4 INI, NR model and other
   Full Pack dependencies. Keep External=true and OverlayMenu=false.
5. Start through your existing FG-enabled launch with SQA_DLSS_FG=1.

SETTINGS
Video > Basic has NVIDIA frame generation and Frame generation inside PiP
scopes. Set the desired switches and Apply. Cancel preserves the old values.
Both choices persist without a renderer restart. The status text reports whether
this process loaded the runtime; the FPS overlay shows actual active/suspended
state. No console commands are needed for these switches. Existing commands
r_dlss_fg 0/1 and the new r_dlss_fg_pip 0/1 remain available.

PiP ON interpolates supported Bodycam Reference scope interiors and the world.
The scope's own depth/motion and previous optical sampling map are transformed
into the final image. Lens color/effects are retained. PiP OFF suspends FG while
scoped; iron sights remain eligible. Unsupported legacy scopes, absent current
Reference inputs, night vision/thermal and existing unsafe UI still suspend FG.
Entry/exit, optic/camera changes and zoom/size cuts reset temporal history.

FPS LIMIT AND COUNTERS
The existing limit targets presented FPS under Reflex, including generated
frames: 100 means about 50 rendered plus 50 generated. With FG off it targets
100 rendered. The target and behavior are unchanged; no user settings were
altered by this build. NR has its own GPU cost.
Rendered and Presented are measured runtime rates, not physical monitor scan-out.
The existing Insert menu, NR controls and wearable scene/UI protection remain.

TESTING LIMITS
GPU input, camera/optical motion, occlusion, reset, UI and Lua checks passed.
A foreground integration interval reported 2x presentations. The full 1800-frame
probe lost foreground focus and failed its strict sustained-generation threshold;
this is not a completed sustained gameplay/visual-quality validation.
Test scope pans, zoom, optic switches, entry/exit, occluding hands, reticles,
Bodycam effects, NR and wearable screens in game. See the validation report.

ROLLBACK
Disable the Test 6 UI/shader mod and restore the complete Test 6 engine package.
Keep the existing OptiScaler companion/INI. No installed game files were changed
while preparing these packages. Do not install this test on the public engine.
